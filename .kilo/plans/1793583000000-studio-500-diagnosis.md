# POST /api/studio 500 Diagnosis Plan

## Symptom Clarification

**Confirmed**: `POST /api/studio` returns HTTP 500.

**Contradiction to resolve**: The catch block (lines 326-333) returns `{ success: false, error: 'Internal server error' }` — never `success: true`. The `AudioContext.jsx:52` MediaError is a **client-side** `HTMLAudioElement.play()` rejection (expired signed URL, codec, CORS), not a server 500. These are two separate issues.

## Diagnosis Plan for POST /api/studio 500

**Action**: Check server logs at the moment of the 500.

```bash

```

**Expected**: The log at line 327 (`console.error('POST /studio error:', error)`) will show the actual error object with `message`, `code`, `stack`.

**Decision point**:
- If error has `code: '23505'` → unique constraint violation (duplicate book?)
- If error has `code: '42P01'` → table missing (migration not applied)
- If error has `code: '23503'` → FK violation (user_id not in users table)
- If error is `PGRST204` → column missing (migration not applied)
- If error is `PGRST301` → table/relation missing

## Diagnosis Plan for AudioContext.jsx:52 MediaError (Separate Issue)

**Line 52**: `await audio.play()` — `MediaError` means the browser refused to play the audio.

**Common causes**:
| `audio.error.code` | Meaning | Fix |
|---|---|---|
| 1 (MEDIA_ERR_ABORTED) | Playback aborted | User navigated away, ignore |
| 2 (MEDIA_ERR_NETWORK) | Network error fetching audio | Check signed URL accessibility |
| 3 (MEDIA_ERR_DECODE) | Codec unsupported | Transcode or use different format |
| 4 (MEDIA_ERR_SRC_NOT_SUPPORTED) | Format/URL unsupported | **Most likely: expired signed URL** |

**Action**: Add logging in `AudioContext.jsx` `onError` (already done in previous fix):
```javascript
console.error('[AudioContext] Audio error:', audio.error);
console.error('Code:', audio.error?.code, 'Message:', audio.error?.message);
console.error('Current src:', audio.src);
```

**If code 4**: The signed URL (1-hr TTL) has expired. The fix in previous turn adds automatic retry with fresh signed URL via `getChapterAudio`.

**Verification**: Open the failing audio URL directly in browser — if 403/404, it's expired.
