# Fix: Blank Page After File Upload

**Date:** 2026-10-13  
**Symptom:** After Google login, uploading a `.txt` or `.md` file produces a blank white page.  
**Scope constraint:** All changes are limited to `client/` only. No server, root config, or Supabase changes.

---

## Root Cause

`Dashboard.jsx` has an `error` state (line 27) that is set in three places but **never rendered in JSX**:

| Location | When set | Rendered? |
|----------|----------|-----------|
| `loadChapterAudio` catch (line 49) | Network error, synthesis error | No |
| `handleGenerate` catch (line 99) | Synthesis failure | No |
| `generateAll` catch (line 122) | Bulk synthesis failure | No |

When the backend is down or an API call fails, `setError(msg)` stores the error in state but the component re-renders with no visible indication of the failure. The user sees a seemingly blank or broken page because:
1. The Error Boundary in `main.jsx` catches any render crash and shows its fallback card
2. Or the book UI renders but with no audio and no visible error message — the user interprets the incomplete state as "blank"

**The fix is purely client-side: make the existing `error` state visible.**

---

## Tasks

### Task 1 — Add error banner to no-book view (`Dashboard.jsx`)

Insert after line 164 (`<BookUploader ... />` div), before `</main>`:

```jsx
{error && (
  <div className="px-4 pb-4">
    <div className="max-w-xl mx-auto rounded-lg p-3 bg-destructive/10 border border-destructive/20 text-destructive text-sm">
      {error}
    </div>
  </div>
)}
```

### Task 2 — Add error banner to book-loaded view (`Dashboard.jsx`)

Insert after line 239 (after the sidebar `<div>` closes, inside the `h-full flex flex-col overflow-hidden` div, before the `</div>` that closes it):

```jsx
{error && (
  <div className="px-4 py-2 border-b border-destructive/20 bg-destructive/5">
    <p className="text-sm text-destructive px-6">{error}</p>
  </div>
)}
```

This places the banner between the main content area and `BottomPlayer`.
