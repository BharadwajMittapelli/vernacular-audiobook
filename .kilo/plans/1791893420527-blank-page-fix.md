# Implementation Plan: Fix Blank Page on localhost:5175

## Problem Summary
Opening `http://localhost:5175` shows a blank white page. Root causes identified:

1. **`client/node_modules/` is empty** — workspace dependencies were never installed into the client folder. Only root `node_modules/` exists (hoisted), but Vite resolves modules at runtime from the local workspace `node_modules/`. Browser loads HTML but all JS imports fail silently → blank page.
2. **`server/node_modules/` does not exist** — server has zero dependencies installed.
3. **`client/package.json` is missing `@supabase/supabase-js`** — `src/lib/supabaseClient.ts` imports it, but it's not declared as a dependency.
4. **Import/export mismatches** (already fixed in previous session):
   - `Dashboard.jsx` — 5 components imported as default but exported as named. Changed to `{ NamedImport }` syntax.
   - `AuthContext.jsx` — `export { default as AuthProvider }` corrected to `export { AuthProvider, useAuth }`.

## Fixed Files (already done, no changes needed)
- `client/src/pages/Dashboard.jsx` — named imports
- `client/src/context/AuthContext.jsx` — removed `default as`
